# 🚀 Landing Page Challenge - Ellos Design

Este projeto foi desenvolvido para o processo seletivo de estágio na **Ellos Design**. O desafio consistiu em criar uma landing page do zero, transformando um esqueleto estrutural em uma interface funcional e moderna.

🔗 **[CLIQUE AQUI PARA VER O PROJETO RODANDO (LIVE) COM BANCO NA NUVEM](https://teste-frontend-developer-22hwny534-ighor-alves-projects.vercel.app/)**

## 🎨 Conceito: Vex Core
Para dar vida ao projeto, desenvolvi a **Vex Core**, uma marca focada em **Cibersegurança**. 
*   **Estética:** Dark Mode com detalhes em Neon.
*   **Objetivo:** Transmitir autoridade, segurança e alta tecnologia.

---

## 🛠️ Tecnologias Utilizadas

### Frontend:
*   **HTML5** Semântico.
*   **Sass / SCSS**: Utilizado para modularização, variáveis e mixins (conforme sugerido nos diferenciais).
*   **JavaScript (Vanilla)**: Manipulação de DOM e interações.

### Backend & Database (Full-Stack):
*   **PHP**: Processamento e validação do formulário.
*   **MySQL**: Persistência dos dados (hospedado via Railway para o live demo).

---

## ⚙️ Instruções para Execução Local

### 1. Requisitos
*   Servidor local (XAMPP, Laragon, etc) com suporte a PHP 8+.
*   MySQL ativo.

### 2. Configuração do Banco
1.  Importe o arquivo `db.sql` presente na raiz do repositório.
2.  **Importante:** O projeto está configurado para a porta **3307**. Caso seu MySQL use a porta padrão (**3306**), altere no arquivo: `/api/dbh.inc.php`.

### 3. Ajuste para Teste Local
Para que o formulário aponte para o seu ambiente local em vez da API de produção:
1. No arquivo `index.html`, localize o método `fetch`.
2. Altere de: `fetch('/api/enviar')`
3. Para: `fetch('../api/formhandler.inc.php')`
